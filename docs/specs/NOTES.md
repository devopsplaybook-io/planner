# Notes

Notes are free-form text entries for capturing information. Each note belongs to
exactly one project and has the following attributes:

| Attribute   | Description                                      |
| ----------- | ------------------------------------------------ |
| Title       | A short name for the note                        |
| Description | The content of the note                          |
| Comments    | Threaded comments on the note                    |
| Attachments | Files attached to the note                       |
| Labels      | Zero, one, or multiple labels for categorization |
| Project     | The project the note belongs to (exactly one)    |
