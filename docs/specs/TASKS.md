# Tasks

Tasks are the core unit of work. Each task belongs to exactly one project and has the following attributes:

| Attribute   | Description                                            |
| ----------- | ------------------------------------------------------ |
| Title       | A short name for the task                              |
| Description | A detailed description of the task                     |
| Checklist   | A list of items that can be marked as done or not done |
| Comments    | Threaded comments on the task                          |
| Assignees   | Zero, one, or more users assigned to the task          |
| Status      | One of the project's defined statuses                  |
| Attachments | Files attached to the task                             |
| Due date    | The date by which the task should be completed         |
| Priority    | Importance level of the task                           |
| Labels      | Zero, one, or multiple labels for categorization       |
| Project     | The project the task belongs to (exactly one)          |
