# User Interface

The web interface is a **Progressive Web Application (PWA)**.
It is installable on mobile and desktop devices and works offline.

## Characteristics

- **Responsive**: Adapts to all screen sizes from mobile to desktop
- **PWA**: Installable with offline support, configured via @vite-pwa/nuxt

## Navigation

- There is a **left side menu** to switch between views
- On mobile, the menu auto-collapses to save screen space
- The menu provides access to: Projects, Tasks, Notes, Calendar, Kanban, and Settings
